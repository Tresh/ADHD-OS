# doc/

Product and development context for ADHD OS.

This directory stores the documents that guide what ADHD OS is, how it is
built, and why decisions were made. It is the place for product context,
architecture notes, and decisions that outlive any single feature.

## Current contents

- `prd.md` — Product Requirements Document (placeholder)
- `architecture.md` — Architecture documentation (placeholder)
- `decisions/` — Product and technical decision log (placeholder)
- `ai-behavior.md` — AI/assistant behavior documentation (placeholder)
- `v1-scope.md` — V1 scope and constraints (placeholder)

## How this folder is used

Most documents here describe context and constraints rather than executable
code. They are meant to be read by humans building ADHD OS so that the
product stays coherent as it grows.

When a decision is made, record it in `decisions/` with the date, context,
alternatives considered, and the chosen path. When the product scope changes,
update `v1-scope.md` so future work has a clear boundary.
