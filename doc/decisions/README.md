# doc/decisions/

Product and technical decision log.

When a substantive decision is made, add a file here with:

- Date
- Context
- Options considered
- Chosen path
- Rationale
- What this decision should protect against later

Keep each decision self-contained so it can be understood without needing
the full history around it.

## Placeholder status

The folder exists now so decisions can be recorded as ADHD OS moves past
the scaffold stage. No decisions have been logged yet because the project
is still at the foundation stage.
