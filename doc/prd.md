# ADHD OS — Product Requirements Document

**Status:** Placeholder — not yet defined.

## Purpose

This document will describe what ADHD OS does, who it is for, and what
problems it exists to solve.

## What we know so far

ADHD OS is a mobile-first web app for ADHD students. It is intended to act
as an adaptive personal assistant that helps users capture, organize, plan,
focus, remember, act, and recover without requiring them to constantly
manage a productivity system.

The current stage is scaffold-only. No V1 features are implemented yet.
